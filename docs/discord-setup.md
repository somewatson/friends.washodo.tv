# Discord Integration Setup Guide

This guide explains how to configure the Discord Developer Portal and environment variables to enable the Washodo Ward bot's authorization and notification system.

## 🛠 Step 1: Create a Discord Application

1. Go to the [Discord Developer Portal](https://discord.com/developers/applications).
2. Click **New Application** and give your bot a name (e.g., "Washodo Ward").
3. Once created, you will be on the **General Information** page.

### Required Credentials
From this page, copy the following:
- **APPLICATION ID** $\rightarrow$ This is your `DISCORD_CLIENT_ID`.

## 🤖 Step 2: Configure the Bot

1. Navigate to the **Bot** tab on the left sidebar.
2. **Token**: Click **Reset Token** to generate a token. Copy this immediately.
   - $\rightarrow$ This is your `DISCORD_BOT_TOKEN`.
3. **Privileged Gateway Intents**: Scroll down to the "Privileged Gateway Intents" section.
   - Enable **Message Content Intent**. (This is critical for the bot to read mentions and commands).
   - Click **Save Changes**.

## 🔑 Step 3: OAuth2 Configuration

1. Navigate to the **OAuth2** tab $\rightarrow$ **General**.
2. **Client Secret**: Locate the "Client Secret" section. If one doesn't exist, click **Reset Secret**.
   - $\rightarrow$ This is your `DISCORD_CLIENT_SECRET`.
3. **Redirects**: Click **Add Redirect**.
   - Enter your public URL followed by the callback endpoint:
     `https://your-domain.com/api/discord/callback`
   - **Example**: If your `BASE_URL` is `https://bot.washodo.tv`, the redirect is `https://bot.washodo.tv/api/discord/callback`.
4. Click **Save Changes**.

## ⚙️ Step 4: Environment Variables

Update your `.env` file with the values gathered above:

| Variable | Source | Description |
| :--- | :--- | :--- |
| `DISCORD_CLIENT_ID` | General Information $\rightarrow$ Application ID | Public ID of the app |
| `DISCORD_CLIENT_SECRET` | OAuth2 $\rightarrow$ Client Secret | Private secret for OAuth2 exchange |
| `DISCORD_BOT_TOKEN` | Bot $\rightarrow$ Token | Token used for bot API actions |
| `BASE_URL` | Your Server | Must match the Redirect URI exactly |

## 🚀 Step 5: Authorizing the Bot

Once the server is running:
1. Visit the `/discord-setup` page in your browser.
2. Click **Authorize for My Server**.
3. Select a server where you have **Manage Server** permissions.
4. Complete the Discord authorization.
5. The bot will automatically create a channel named `📯-ward-bot` in that server and save the integration to the database.

## ❓ Troubleshooting

### `invalid_oauth2_redirect_uri`
This error occurs if the `BASE_URL` in your `.env` does not exactly match the Redirect URI entered in the Developer Portal. Ensure there are no trailing slashes or protocol mismatches (`http` vs `https`).

### Notification Channel Not Created
If the bot is added to the server but the channel is not created, ensure:
1. The `DISCORD_BOT_TOKEN` is correct.
2. The bot has the `MANAGE_CHANNELS` permission (this is requested automatically by the invite link generated by the bot).
3. Check the server logs for `[Discord Client] Error creating channel`.

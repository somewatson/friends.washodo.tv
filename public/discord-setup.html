🚀 Setup Guide
  • 1
    Click the "Authorize for My Server" button above.
  • 2
    Select the server where you wish to add the bot from the dropdown menu. (You must have Manage Server permissions).
  • 3
    Review the requested permissions on the Discord authorization screen.
  • 4
    Click Authorize to complete the process.
🛡️ Permissions & Privacy

We only request the permissions necessary for the bot to function correctly. Here is exactly why we need them:

Permission Why we need it
View Channels Required to find the channels where you've asked for our help or where notifications should be posted.
Send Messages Allows the bot to respond to your commands and post live stream alerts.
Send Messages in Threads Essential for the bot to participate in organized discussions and respond within threads.
Read Message History Helps the bot understand the context of a conversation when it is mentioned.
Embed Links Allows us to send beautifully formatted "Embed" messages with stream thumbnails and links.
Privacy Guarantee: Washodo Ward is designed to be unobtrusive. The bot only processes messages where it is explicitly mentioned by its username/ID or when a slash command is used. It does not scrape private user data or monitor general conversations.
